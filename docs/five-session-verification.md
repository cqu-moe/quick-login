# 五份独立 SSO 会话并存短测

2026-09-09 21:43（Asia/Shanghai）完成。结论：**短测通过**。

来源是当前生产 `cqu-moe-auth` 导出的 `CquLoginContainer` 类，创建五个固定独立实例，沿用该类 APAC 区域约束。未调用旧腾讯云服务器，未修改生产 Auth。

串行完成五次真实学校登录，每份导出 8 个仅属于学校 SSO 域的 Cookie。五份 `SOURCEID_TGC` 去重计数为 **5**，不是重复复制同一个会话。第 5 份登录完成后，再分别用五个全新的本机 HTTP Session（关闭环境代理）携带对应 SSO Cookie 请求学校 CAS。

| 会话 | CAS 响应 | 获得新 ticket | 耗时 |
|---|---|---|---|
| 1 | 302 | 是 | 442 ms |
| 2 | 302 | 是 | 884 ms |
| 3 | 302 | 是 | 337 ms |
| 4 | 302 | 是 | 374 ms |
| 5 | 302 | 是 | 312 ms |

验收检查了重定向目标为学校门户并包含新签发的 ticket，未输出 ticket 值。五份会话建立后，最早会话仍能出票，未观察到后面的登录挤掉前面的会话。

## 范围

这证明五份独立 SSO 会话在本轮短时间窗口内可以共存，且 Cloudflare 来源的 Cookie 可在本机直连出票。五份接收会话位于同一本机出口，不等同于五台实体设备或五个本地 IP。没有验证 1 小时保活、7 小时强制重登后的长期并存，也没有完成业务系统浏览器端登录；本轮不跟随 ticket 回调。

## 清理与证据

Cookie 和密码仅在本轮 Python 进程内存持有，进程已结束；无 Cookie 导出文件。临时入口设置令牌、固定账号、固定五槽位、1 小时失效和关闭观测日志。测试结束删除临时 Worker 与本地 `private.mjs`；没有清理或注销生产会话。

脱敏原始结果：`experiment/five-session/result.json`。可复核脚本：`experiment/five-session/run.py`、`worker.mjs`（不含有效令牌）。
