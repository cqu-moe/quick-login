# CQU 快速登录插件设计

[正式设计稿](superpowers/specs/2026-09-09-quicklogin-design.md)已汇总当前确认内容：

- 每安装实例专用 SSO 会话；云端每小时保活、每 7 小时强制重登。
- 管理员设备额度、网页总开关、插件子开关；额度降低保留最近联系的设备，超额设备停用但不强制退登。
- 网页设备列表展示浏览器、在线状态、最近联系时间与最近 IP，支持指定设备强制退登。
- 插件 OAuth + PKCE 与设备 grant 鉴权，后台每 5 分钟检查 Cookie 版本，无需额外激活或手动导入。
- 下载和写入暂时失败有限重试；写入后学校仍要求登录，直接提示手动登录。
- UI 以 emil-ask-emil 为设计入口，设计、实现和交付前必用 emil-unslop-design。

[五会话短测](five-session-verification.md)通过：5 份不同会话全部建立后，本机 5/5 能取得新 ST。完整 Chrome 业务登录和长期维护仍需在实现验收中验证。

[详细实施计划](superpowers/plans/2026-09-09-quicklogin-implementation.md)已生成：共 18 个顺序任务，附公共接口、逐项测试、迁移和验收要求，可交给编程模型执行。

当前已交付设计与实施计划，未实现或部署正式插件。
