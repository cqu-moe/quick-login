# QuickLogin 0.5.3

Date: 2026-10-22

- 首次连接 Auth 后持续显示学校登录准备进度，不再短暂误报“此设备已关闭”。
- 开关与此浏览器的有效状态保持一致；恢复快捷登录时可以及时关闭，不再因等待网络锁住界面。
- 学校登录页提供更新密码、重新连接、切换已有登录等具体入口；开始输入后立即切换为手动登录。
- 明确区分账号暂停、此浏览器关闭、手动模式和已有学校登录，并补充状态说明。
- 配套 Auth 支持识别商店版和 Canary 的对应设备，改进重连、授权说明与学校账号管理入口。
- 保留已有学校登录的 Cookie 保护和同步确认条件；沿用 0.5.2 恢复的工具栏弹窗尺寸。
