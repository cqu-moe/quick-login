# QuickLogin 0.4.6

Date: 2026-10-13

- 诊断事件升级到 telemetry v2：补齐自动、手动、无操作和失败结果的触发方式与耗时，Cookie 应用单独标记为未验证登录。
- 遥测改为有界后台发送，不再等待诊断上报后返回关键插件操作；无采集配置时保持无操作。
- 扩展关闭会话录制、自动采集、性能/热图/死点击、conversations、Web 实验、控制台日志、调查、产品导览、功能开关请求和用户画像，仅发送有限字段与稳定错误码。
- 官网仅在 quicklogin.cqu.moe 自有页面启用脱敏录制，屏蔽输入值、动态文本、DOM 属性、图片、iframe、canvas 和网络内容，不录制学校站点或其他标签页。
