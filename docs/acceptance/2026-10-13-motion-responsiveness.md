# 2026-10-13 动效与界面响应验收

范围：QuickLogin 0.4.5 工作区候选版本，扩展 popup、学校登录页提示和官网。保留现有品牌、协议、Cookie 所有权与后台操作语义。界面等待超时不代表后台操作已取消；恢复按钮只重新读取状态，不自动重发用户命令。

## 已复现并修复

- popup 首次读状态或提交操作永不回包：旧版持续显示忙碌；现在 10 秒后显示可恢复提示，并忽略迟到回包。
- popup 消息拒绝或返回 `accepted:false`：旧版可能出现未处理的 rejection 或静默回到旧状态；现在提示操作未确认。
- storage 事件风暴：旧版 101 次事件产生 101 次并行状态读取；现在最多一条在途读取，合并保留一次尾部刷新。
- 开关点击前启动的读取稍后返回：旧版覆盖“正在同步”；现在按用户操作代次忽略旧结果。
- 点击后重建整个 popup：旧版替换开关并丢失键盘焦点，CSS 无法连续插值；现在复用节点、即时更新反馈，并在控制项隐藏时转移焦点。
- 主操作完成但最终状态仍未读回：继续阻止重复点击，避免恢复／同步操作被再次提交。
- 学校页面每 200ms 改动 DOM：旧版两秒内发出 11 次检查；现在自动检查最多每五秒一次。首次表单出现仍会触发检测，不等待无限延后的 debounce。
- 用户开始输入后旧自动检查回包：不再回滚手动提示；未响应的学校页消息提供手动登录入口。
- `pagehide` 后停止定时器和监听，`pageshow.persisted` 后恢复；重复学校页提示不再替换已聚焦按钮。
- 官网下载和复制操作的等待设上限；密集 focus 刷新合并，复制恢复计时器和离页清理保护迟到结果。

回归入口：`npm test -- src/popup/main.test.ts src/content/index.test.ts website/src/download.test.ts`。新增故障场景均先观察失败，再修复。

## 动效策略

高频状态文字即时更新，不给整个 popup 添加反复入场或逐项动画。保留 180ms 开关位移、120ms 颜色反馈及 150ms 轻微按压；键盘操作不缩放、不开过渡。系统减少动态偏好下停止 spinner 和位移，仅保留轻微颜色反馈。页面隐藏时暂停 popup spinner。官网 hover 只对精细指针启用，静态插件演示同步使用最新样式。

## 浏览器证据

使用 Ego Lite 的独立任务空间，实际渲染本地源码，并以合成的授权/同步状态替代 Chrome 消息接口；未操作真实用户设备或学校 Cookie。

- 390×468 popup：鼠标点击立即显示“正在关闭”，开关 transition 180ms；键盘 Space 后焦点仍在开关，transition 为 0s。
- 连续 1000 次状态事件产生 1 次读取；100 次快速点击产生 1 次开关命令，开关 DOM 节点不变。
- 上述压力片段没有检测到大于 50ms 的 Long Task。初始开发页面加载有 67–68ms 的长任务，单独清零统计后才测操作片段；该结果不等于承诺所有设备 60fps。
- 减少动态且深色模式：spinner animation 为 none；10 秒无回包后显示“操作暂未确认”和“重新检查”，布局无裁切。
- 官网 390×844 无水平溢出；1440×1000 桌面布局已目视检查。
- 官网实际 Clipboard 连续复制后恢复原标签，`aria-busy=false`；减少动态模式按钮只过渡颜色／透明度。
- 官网真实前进／后退返回下载页正常，但本次开发服务器未命中 bfcache。另在真实浏览器派发持久化 pagehide/pageshow 事件验证：离页后复制不再执行，恢复后重新显示“已复制”；不把事件模拟当作实际缓存命中。
- localhost 官网请求生产下载资格时进入可重试错误态，未证明认证下载成功。

## 构建与发布边界

共享 UI 消息模块会被普通多入口打包提取为 ES chunk，因此学校页内容脚本独立构建为 IIFE，构建同时要求只生成一个入口文件且无静态／动态 chunk 依赖。`check:package` 使用经典脚本解析验证最终 manifest 引用，避免 Chrome 内容脚本出现 import 语法错误；此检查已在修复前失败、修复后通过。

自动化、构建和本地浏览器测试不等于已加载 Chrome 扩展、完成真实学校 SSO、通过 CI、发布官网 canary 或上传 Chrome Web Store。发布状态见运维记录。
