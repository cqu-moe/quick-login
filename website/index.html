减少重复登录

通过 Auth 维护学校会话，将统一认证所需的 Cookie 同步到浏览器。学校要求验证或会话需要恢复时，插件会提示下一步。

02 /

每台设备，各自管理

每次安装拥有独立授权。你可以在 Auth 查看和管理设备，也可以只关闭当前浏览器的快捷登录。

03 /

已有登录，由你决定

遇到浏览器里已有的学校登录，插件会保留它。由你明确选择切换后，再使用 QuickLogin 的会话。
