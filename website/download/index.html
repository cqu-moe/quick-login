THREE STEPS TO START

几步，装好。

  1. 1

    下载并解压

    登录 Auth 后返回本页，点击“下载”。将 ZIP 解压到一个固定文件夹。不要删除或随意移动这个文件夹，Chrome 会从这里读取插件。

  2. 2

    在 Chrome 中加载

    在地址栏输入 chrome://extensions，打开“开发者模式”，点击“加载已解压的扩展程序”，选择刚才包含 manifest.json 的文件夹。

  3. 3

    打开插件，连接 Auth

    点击工具栏的 QuickLogin 图标，按提示连接 Auth 并授权。需要绑定学校账号或完成验证时，在 Auth 按提示操作。等待插件显示“已就绪”。

    前往 Auth 管理 ↗

已经安装，如何更新？

下载新版本，将解压后的文件覆盖到原来的安装目录，然后在 Chrome 扩展管理页点击 QuickLogin 的重载按钮。保留原目录和安装记录，不要先卸载重装。

内测包不会自动更新。遇到安装或授权问题，可以先查看常见问题。
