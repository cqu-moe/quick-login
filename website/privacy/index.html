PRIVACY, IN PLAIN WORDS

哪些数据，为什么需要。

下面说明 QuickLogin 扩展、官网和 Auth 在使用过程中的数据处理边界。

本说明对应当前内测实现，更新于 2026 年 10 月 13 日，由 CQU.MOE 提供。本项目不是重庆大学官方产品。

浏览器扩展做什么

插件通过 Auth 获得设备授权，并将限定于 sso.cqu.edu.cn 的统一认证 Cookie 同步到浏览器。插件自身不读取或保存学校密码。已有且不属于插件的学校登录，会等待你明确选择切换。

权限用于什么

  • Cookie：读取、写入并核验学校统一认证会话。
  • 本地存储：保存当前设备授权、设置与同步状态。
  • 定时任务：在后台检查并同步会话。
  • 身份授权：通过 Auth 登录并连接当前安装实例。

扩展的站点访问范围包括 Auth、学校统一认证与 CQU.MOE 的诊断服务；当前不支持无痕模式。

Auth 与官网

Auth 处理账号登录、内测资格、设备授权和云端学校会话。学校凭据及验证信息在 Auth 的绑定与会话流程中处理；“扩展不保存学校密码”并不表示 Auth 不处理凭据。

官网用已有 Auth 会话查询下载资格。点击下载时，Auth 再次校验登录与资格，从私有存储返回安装包。官网不在浏览器本地存储中保存登录令牌，也不提供免鉴权文件链接。

诊断信息

扩展在构建启用诊断配置时，会通过 CQU.MOE 诊断代理发送操作结果、错误代码、扩展版本和随机生成的安装标识，用于定位故障。发送前会清理敏感字段及 URL 查询参数。

当前扩展配置关闭自动页面采集、会话录像与异常采集，不创建个人画像，也不发送异常原文或堆栈。诊断不应包含学校密码、Cookie、验证码或授权令牌。

官网仅在 quicklogin.cqu.moe 自有页面启用脱敏会话录像：输入值、动态文本和 DOM 属性默认遮蔽，事件中的 URL 只保留站点来源，图片、二维码、iframe、canvas 和网络正文/请求头不录制；学校站点、浏览器其他标签页和终端不在范围内。官网录制不创建个人画像。

服务商与数据用途

官网和 Auth 使用 Cloudflare 承载服务及存储。启用诊断时，CQU.MOE 的诊断代理将必要的故障与操作数据交由 PostHog 处理。 这些服务用于提供设备授权、会话同步、安全保护和故障排查；网络服务在处理请求时可能接触来源 IP 与请求元数据，不能把诊断配置中关闭 IP 采集理解为所有基础设施都不处理 IP。

本项目不出售用户数据，不将数据用于与快捷登录无关的广告、信用评估或借贷用途。 服务商的数据说明可参阅 Cloudflare 隐私政策和 PostHog 隐私政策。

保存与删除

当前设备的授权令牌、设置和同步记录保存在扩展本地存储中；用于回滚的旧 Cookie 快照保存在浏览器会话存储中，不作为诊断上传。卸载扩展会清除扩展的本地存储，但不会替你退出学校业务网站。

Auth 中的设备、授权和会话记录以及诊断服务中的历史事件与服务日志具有各自的保存周期，撤销授权不会自动删除全部历史记录。本项目目前不承诺统一的自动删除期限。 如需了解具体记录的保存情况或申请删除，请联系 uu@401.moe，我们会按对应服务中的实际记录处理。不要在删除申请中发送密码、Cookie 或令牌。

你可以怎样控制

你可以通过插件开关暂停当前设备，或到 Auth 设置管理和撤销设备授权。撤销授权不等于立刻清除所有学校网页已建立的业务会话；如需退出学校服务，请使用相应网站的退出功能。

隐私问题和产品支持请联系 uu@401.moe。反馈问题时，不要提供密码、完整 Cookie、验证码或访问令牌。数据处理方式发生变化时，会更新本说明及对应版本的更新记录。
