A LITTLE HELP

你可能想问。

从安装到日常使用，先看看这里。

为什么显示“内测中，暂未开放”？

你的 Auth 账号目前没有 QuickLogin 内测资格。官网介绍与指南可以公开查看，安装包仅向已有资格的用户提供，当前不开放申请。

为什么要登录 Auth 后才能下载？

Auth 会确认你的登录状态与内测资格。登录成功后会回到下载页面，再点击“下载”即可取得安装包。

支持哪些浏览器和设备？

首版安装指南面向桌面 Chrome。手机不能按此方式安装；其他 Chromium 浏览器尚未作为本次交付的正式支持范围。

为什么需要打开开发者模式？

当前通过 ZIP 内测包分发，尚未从 Chrome Web Store 安装。解压后使用“加载已解压的扩展程序”，选中包含 manifest.json 的目录。

显示“已有学校登录”怎么办？

QuickLogin 会保护浏览器中已有的学校登录。你可以继续使用它；如果希望切换为 QuickLogin，会由插件提示你明确确认。

显示“前往 Auth”或需要重新连接怎么办？

前往 Auth 按提示恢复原设备授权。更新插件时保留原安装目录和设备记录，避免通过卸载重装重复占用设备名额。

“已就绪”是否代表所有学校网页都一定能登录？

“已就绪”表示插件已完成当前会话的同步确认。具体学校服务仍可能要求额外验证、受到服务状态影响，或使用不同的登录方式。

能自动更新吗？

当前内测 ZIP 包需要手动更新。下载新版、覆盖原目录，再到 Chrome 扩展管理页点击重载。

关闭和退出有什么区别？

关闭当前插件开关会暂停这台设备的快捷登录；退出设备会撤销它的授权。网站总开关影响整个账号，具体操作与提示可在 Auth 中查看。
