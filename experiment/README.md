# 临时 SSO 迁移实验工具

这是可丢弃的验证工具，不是正式插件，不部署到生产 Auth。

## 组成

- `serve.py`：仅监听 `127.0.0.1:18746`，提供实验输入与状态页面；检查 Host、会话令牌和 Origin，不设置跨域访问。密码与导出的会话只在进程内存中处理。
- `remote_probe.py`：通过现有 SSH 配置，以原登录服务用户运行临时 Python 进程，复用现有登录库。最多建立两个测试会话，不启动 systemd 服务、不写入 Auth 数据库。敏感协议输出仅由本机控制进程接收，不打印到日志。
- `extension/`：Chrome Manifest V3 实验扩展。仅声明 `cookies` 和 `https://sso.cqu.edu.cn/*` 权限，没有内容脚本、后台脚本或网络上传能力。CSP 禁止网络连接。

## 实验边界

本轮远端为原腾讯云登录服务器，用于检查服务器到本机的跨网络会话迁移。结果不能直接替代当前 Cloudflare 出口实测。

扩展只接受本轮导出的 SSO 专属域 Cookie，拒绝父域、其他域、分区 Cookie、不支持的属性、重复条目或已过期条目；如实际需要这些属性，应先检查数据，再调整实验，不能把工具主动拒绝误判为学校会话不能迁移。

导入前若发现已有非空 SOURCEID_TGC（含对 SSO 生效的父域 Cookie），会停止操作。缺少该凭据时，允许覆盖同名的残留 SSO Cookie，避免仅访问登录页就无法导入。请在独立 Chrome 测试资料中加载扩展；不要为了满足此前置检查而清除正在使用的浏览器会话。

Cookie 导入并回读成功、服务器探测可以出票，都不能替代业务页面登录验收。须从正常业务入口确认至少两个 CAS 接入系统实际登录成功，并记录新会话建立前后旧会话的可用性。学校是否限制并发登录仍未知，新登录可能影响旧会话。

## 使用

1. 启动 `python3 experiment/serve.py`，需要 SSH 与本机监听权限。专属页面链接存于权限 0600 的 `/private/tmp/cqu-sso-probe-local-url`，不公开分享。
2. 在页面输入本次授权的学校账号、密码与验证码。最多创建会话 A、B；不要将学校密码写入源码或 shell 参数。
3. 用户批准后，在独立 Chrome 测试资料的扩展管理页启用开发者模式，加载本目录下的 `extension` 文件夹。
4. 从实验页面导出相应会话的 SSO Cookie JSON，再通过扩展文件选择器导入。扩展不会导入业务 Cookie 或 localStorage，也不会自动访问业务网站。
5. 从学校门户正常进入业务系统验证，再执行服务端测试会话探测。`alive` 只表示该会话可继续取票，不证明实际业务页面已登录。

导出文件包含登录凭据，请勿分享或上传。扩展只在页面内存中处理它，不把内容保存到扩展存储。导入后的 Cookie 会按学校设置留在测试资料中。

## 清理

结束时停止本机 `serve.py`，它会关闭 SSH 输入、结束临时进程并释放本机内存状态。随后移除实验扩展、临时链接与下载的 Cookie 文件，关闭独立测试资料。不要通过调用学校全局退出接口清理，以免影响其他会话。

## 已执行的工具检查

- 两个 Python 文件语法编译通过。
- 浏览器脚本语法检查通过。
- 使用合成 Cookie 检查域隔离、过期、分区属性、必需 TGC 和 HttpOnly 保留。
- 本机控制接口的 Host、令牌、Origin 拒绝路径及 no-store 响应检查通过。

以上是工具检查，不是学校登录或迁移成功证据。

API 依据：[Chrome Cookies API](https://developer.chrome.com/docs/extensions/reference/api/cookies)。
