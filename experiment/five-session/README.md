# 五份 SSO 会话短测

使用生产 `cqu-moe-auth` 导出的 `CquLoginContainer` 类，通过独立实例顺序建立五份会话。只在 Python 内存持有 SSO Cookie；第 5 份成功后才分别通过本机直连请求学校 CAS，检查是否签发新的 ticket。记录 `SOURCEID_TGC` 去重数量，不记录值。

临时入口限制令牌、有效期、固定 1–5 槽位和本轮授权学校账号，观测日志关闭。测试结束删除临时 Worker 和 `private.mjs`。本目录未提供有效令牌，不能直接调用。

这里只验证五份会话短时并存和跨来源出票；不代表五台实体设备、长期保活、强制重登后并存或完整业务系统登录均已通过。
